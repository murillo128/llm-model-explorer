# Qwen3.5 NVFP4 language description

The explicit `register_qwen35(registry)` entry point describes the reviewed
`Qwen3_5ForConditionalGeneration` language path. Startup assembly belongs to its
own child. It does not import Transformers, construct a model, access the network,
trace, run a recurrence, read tensor payloads, or add numeric decoding. Both hybrid
interiors, both residual paths, and every concrete decoder instance are emitted.

## Mathematical review map

`Qwen3_5DecoderLayer` and `Qwen3_5MLP` preserve pre-normalization, attention,
residual addition, post-attention normalization, separate SiLU gate/up MLP paths,
multiplication, down projection, and the second residual addition. The 24 actual
reference instances retain the configured full-attention indices 3, 7, 11, 15,
19, 23. Explicit `layer_types` overrides the interval default as in the source.

`Qwen3_5Attention` projects `[B,T,H]` into `2 * heads * head_dim`, reshapes into
`[B,T,heads,2*head_dim]`, then splits the last axis. Query and gate weight rows
are **interleaved per head**, not two contiguous global halves. Query and key
use zero-centered RMSNorm (`1 + weight`). Partial interleaved T/H/W RoPE rotates
the first quarter of each head and preserves the rest. Symbolic prior/current KV
concatenation precedes grouped KV replication, scaled QK product, causal/padding
mask, softmax, value product and head merging. Sigmoid of the separate gate
multiplies attention output before `o_proj`. Prior and next KV ports describe
state, not an observed cache. `K` means `P + T`; none of these symbols assert an
executed input or captured runtime sequence length.

`Qwen3_5GatedDeltaNet` first masks padding, projects QKV, z, b and a separately,
and performs causal depthwise convolution on QKV only. Convolution state and
recurrent state are distinct symbolic prior/next records. SiLU follows local
mixing; Q/K/V split widths and head reshapes follow the configuration. Q/K heads
repeat to match value heads, receive L2 normalization with epsilon 1e-6, and Q
is additionally scaled by the inverse square root of the key head width.
`beta = sigmoid(b)` and `g = -exp(A_log) * softplus(a + dt_bias)` independently
feed the delta-rule operation. Its explanatory formula is the reviewed recurrent
fallback's update, at algorithm abstraction:

```text
D = exp(g_t) * S_prev
correction = beta_t * (v_t - k_t^T D)
S_next = D + k_t correction^T
y_t = q_t^T S_next
```

This is non-executable text; neither recurrence nor chunk computation runs.
The output uses ordinary weighted RMSNorm (not zero-centered), then multiplies
SiLU(z), merges value heads and applies `out_proj`. This distinction prevents
incorrect reuse of dense/Llama normalization fragments.

The embedding table and final zero-centered RMSNorm precede the tied vocabulary
projection. Both config levels declare tying, and the selected storage omits
`lm_head.weight`; the alias resolves to the complete native embedding table.
Visual components stay context-only. Additional `mtp.*` tensors in the checkpoint
are marked contextual unused auxiliary weights: this reviewed Transformers
conditional-generation language path never invokes MTP. They are not described
as extra decoder layers or evidence of MTP execution. Complete coverage means
this declared language path, not visual processing, auxiliary prediction, or
other Qwen/MoE variants.

## Storage and selection

Admission's `nvfp4_storage_names` validates the physical encoding groups; both
admission and this description call that same metadata-only function. This
change only widens its descriptor input to the shared dtype/shape protocol.
Semantic binding checks actual model dimensions against the admitted geometry:
U8 weight `[out,in/2]`, F8_E4M3 scale `[out,in/16]`, scalar F32 global weight and
input scales. All four remain descriptive storage, never neural operations or
pretend float32 matrices. Fused query/gate records retain logical row geometry
and name the original packed source; they require a view and expose no endpoint.
Native rank-three convolution retains its shape and has unsupported-rank
inspection. Native rank-one/two parameters use only existing inventory IDs.

The selector checks exact class/model discriminators, bounded dimensions,
recognized options, normalization/activation/gating, supported rotary geometry,
tied-head declarations, storage geometry and hybrid ordering. Missing structural
configuration, unknown options/types, contradictory shapes, malformed NVFP4
metadata, or orphan scales cannot claim support. A completely missing required
parameter is localized as unresolved in an otherwise useful partial graph.
Absent fused storage cannot manufacture an actionable region endpoint.

## Validation and acceptance boundary

Focused topology, geometry, native/packed/fused/alias inspection, partial and
invalid fixture tests are in `tests/test_qwen35_architecture.py`. Read-only local
fixture analysis intercepts network, model construction/calls, tracing,
materialization, processor/generation and tensor-reader entry points. Pinning
uses the existing separately tested bounded content fingerprint path.

Actual-checkpoint acceptance is **pending**: source review and captured complete
header metadata are not validation of a complete locally installed checkpoint.
No model payload or actual checkpoint fingerprint was available for this issue's
fixture run. Integrated acceptance must supply and validate the complete selected
local assets and record timing/memory/fingerprint evidence. Static tests do not
claim numeric equivalence, inference correctness, or decoder support.
